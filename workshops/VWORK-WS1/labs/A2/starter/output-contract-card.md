# A2: Output Contract Card (starter)

The exact artifact your Skill must produce, every time, from any set of raw notes. This is the contract you encode inside the Skill (not something you re-type in each prompt).

## Target artifact: Weekly Status Update

**Structure (exact sections, in this order):**

1. **Summary**: one or two sentences on overall status.
2. **Progress**: bulleted, what moved forward.
3. **Blockers and risks**: bulleted; each names the owner and any deadline.
4. **Decisions**: bulleted; what was decided.
5. **Open questions**: bulleted; unresolved items needing a call.
6. **Action items**: a table with columns: Owner, Action, Due.

**Tone:** neutral, concise, business. No filler, no restating the raw notes verbatim.

**Length:** fits on one screen. Bullets are single lines where possible.

**Rules:**

- Every action item must have an owner and a due date; if the notes omit a due date, write "TBD".
- Do not invent facts not present in the notes.
- Preserve names as written in the notes.

## Why this is the contract

If two people run the same Skill on different notes, both outputs have these six sections in this order, the same tone, and the same action-item table shape. That consistency is the point of a Skill.
