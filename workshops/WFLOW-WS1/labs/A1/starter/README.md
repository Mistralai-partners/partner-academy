# A1 starter

This is the A1 starter for the WFLOW-WS1 Mistral Workflows workshop.

Drop these files into a project created with
`uvx mistralai-workflows-cli@latest setup` (or run setup first, then replace the
`src/workflows` contents):

- `src/workflows/confirm_order.py` goes into your scaffold's `src/workflows/`.
- `verify.py` goes into your scaffold's project root.

Then follow `../TASKS.md`.
